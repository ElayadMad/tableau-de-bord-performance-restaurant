### Comment obtenir de belles captures
1. Ouvrir `Tableau-de-Bord-Restaurant.pbix` dans Power BI Desktop.
2. Passer chaque page en plein écran (icône **Mode Focus** ou `F11`), puis capturer :
   - **Windows** : `Win + Maj + S` (outil Capture) → enregistrer en PNG.
   - Ou **Fichier ▸ Exporter ▸ PDF**, puis extraire les pages en PNG.
3. Renommer selon le tableau ci-dessus et déposer dans ce dossier.

> Astuce : une largeur d'image d'environ **1600 px** offre un bon rendu sur GitHub.
